# Braitenberg Lab

A browser-based Braitenberg vehicle simulator. Open `index.html` directly in a
modern browser; it has no build step, server, or external dependencies.

Use the on-screen controls to add and remove light-seeking vehicles,
light-avoiding vehicles, and standalone lights. Standalone lights can be
dragged around the simulation. Motion trails and vehicle-mounted lights can be
toggled from the interface or with the `T` and `L` keys.

The original Pygame implementation is preserved in `brait.py` for reference.
